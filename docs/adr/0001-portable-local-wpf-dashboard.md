# Portable local WPF dashboard

The first release is a self-contained C#/.NET WPF Windows application that processes CSV data locally and does not require hosting, accounts, network services, installation, or administrator access. This keeps sensitive supervisor data on the workstation and favors a simple portable deployment over a browser or hosted architecture; future multi-day reporting remains possible because the loaded data model is date-aware even though the initial view is one day at a time.
