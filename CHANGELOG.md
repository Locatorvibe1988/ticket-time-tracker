# Changelog

## [1.1.0] - 2026-08-05

### Added

- Selectable Assigned Team filtering with team-first grouping in the Daily timeline and summary.
- Configurable CDC List colors for 001, 002, 004, 005/006, 009, and other codes.
- Diagonal split markers when multiple CDC colors share one 15-minute bucket.
- Persistence for the selected team, timeline mode, and CDC color settings.

### Changed

- CDC counts and timeline markers now use the configured color palette with readable text contrast.
